# Incident
- Refers to a violation of a company’s security policy [^3] or an adverse network event in an information system or network or the threat of the occurrence of such an event. [^2] #glossary 
- An [Event](event.md) transforms into an Incident if the outcome is some kind of unwanted or unplanned effect on the system(s) involved. [^1]
- Unusual Event [^4]
- Encompasses any adverse event that threatens the security of an organization’s information systems. [^4]
- All [breaches](breach.md) are incidents but not all incidents are breaches. For example, system crashes or suspicious activity. [^4]
- Prevention through employee cybersecurity training, regular software updates, and the implementation of network monitoring tools. [^4]
- Identification through intrusion detection systems and vigilant monitoring of network traffic for anomalies. [^4]
- Remediation through isolation of affected systems, removal of malware, and restoration of data from backups. [^4]

- See also [Event Severity Scale](event-severity-scale.md)
